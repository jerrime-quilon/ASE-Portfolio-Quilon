Course Introduction
Agentic Software Engineering and Responsible AI is a course that focuses on understanding how artificial intelligence can help in developing software systems. It also teaches the importance of using AI responsibly, protecting information, and making sure that technology is safe and helpful to people.

As a Computer Engineering student, I see this course as an opportunity to learn more about how AI works and how it can be applied to real-world situations.

Personal Learning Goals
Through this course, I hope to:

To understand the basic concepts of Agentic Software Engineering.
To learn how AI agents work and how they differ from traditional applications.
To improve my skills in using GitHub and other software development tools.
To understand the importance of teamwork and Agile methods.
To learn how to use AI safely, responsibly, and ethically.

Reflection from Part A

After learning about Agentic Software Engineering, I learned that Agentic Software Engineering allows AI agents to perform tasks and make decisions with less human involvement. I also understood that Agile methods help developers improve their systems through continuous testing and feedback. However, AI can still make mistakes, so developers must consider security, privacy, and human supervision when creating AI-powered applications.
